# Full review and fixes · 2026-11-06

The review started at `cb8549a`. The seller server, buyer/plugin, and UI were reviewed separately. Confirmed defects were reproduced in regression checks and then fixed.

**Assessment: the local development flow remains usable. Live selling is not ready.** Live selling stays disabled. These fixes do not establish that wallet authentication, real model execution, or onchain payments are complete.

| Priority | Confirmed issue | Fix |
| --- | --- | --- |
| P1 | A slow purchase status response overwrote a new approval and nonce | Merge the latest ledger row inside a transaction. Do not revert completed states with stale responses. |
| P1 | Incorrect Hermes `ctx.get_config()` arguments broke buyer tools | Use the v0.22.7 key/default calling convention. |
| P1 | Quotes and approvals were accepted after the worker stopped | Apply the same readiness conditions to status checks and admission. Recheck after asynchronous verification. |
| P1 | Switching services or drafts during a request attached its response to the wrong screen | Block switches during requests, lock to one action at a time, and check the draft version. |
| P1 | Advanced JSON silently overrode the visible price and payee address | Accept only input/output schemas and examples; reject other fields. |
| P1 | Restored orders displayed the latest republished contract | Return the original revision's public `service_contract` in order responses. |
| P2 | Losing a quote response also lost the recovery ID | Return the saved purchase ID even on failure. Query and recover with the same request key. |
| P2 | An expired, unaccepted approval continued to reserve the purchase budget | Release the reservation only when a fresh query started after expiry confirms that admission did not occur. |
| P2 | The connection button disappeared after session expiry | Show reconnect controls on a 401 response. Do not approve again automatically. |
| P2 | Republishing while a page was open caused repeated attempts with the stale quote | Provide **Review latest contract**. Keep only compatible input and require the user to request a new quote. |
| P2 | Invalid JSON and boolean or fractional prices were not handled correctly | Validate finite JSON numbers, valid UTF-8, and integer prices. |
| P2 | Owner tests created new executions while restore protection was active | Apply restore readiness conditions to free tests as well. |
| P2 | Inconsistent payment success responses were trusted | Check the transaction hash format and returned amount; retain `unknown` when they do not match. |
| P2 | Forms mishandled boolean enum types, array edits, and optional objects | Preserve original types, synchronize validation with the current value, and let users include or omit optional objects. |

The management UI now lets owners reopen saved versions. Bundles with original reference files cannot be overwritten through the single-file SKILL.md editor.

The UI was rebuilt around the [Hermes design reference](ui-design.md), with compact controls, flat work areas, fixed navigation on the left, and an order or publishing panel on the right.
